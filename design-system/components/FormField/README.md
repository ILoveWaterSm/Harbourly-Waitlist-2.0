The waitlist form kit: progress bar, mono step counter, big question, input, textarea, counter, error line and dashed add button.

Inputs are `fill-subtle` with a `line`-weight border and `radius-md`; focus swaps the border to `green` and adds `shadow-focus`. Ask one question per screen with the step counter in the form `02 / 05`. Errors are amber, one line, under the field. Placeholders and counters use `subtle` (below 4.5:1), so never put a required label in that colour.
