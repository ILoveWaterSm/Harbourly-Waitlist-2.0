A dark card with a top glow line, used to show product moments (coach profile, session recap, dashboard) beside a feature heading.

Use `hb-mcard` for illustrations of the product, one per feature, at most 440px wide. Framing comes from the top glow line and a deep shadow, not from a border or boxed icons. Inside, use mono for every figure and label, dashed rules (`hb-mc-dash`) between groups, and green only for verified state, trends and the current bar. Sample figures in the preview are placeholders.
