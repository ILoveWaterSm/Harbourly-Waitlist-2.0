A selectable card with a mono tag, a 60px icon chip, a Sora title and a short description.

Use two or three `hb-role` cards in a grid (one column below 1000px). On selection add `sel`: the border and ring turn green, the chip fills green with `green-ink` stroke, and a check badge appears top right. Consumers provide the radio behaviour and should expose it as `role="radio"`.
