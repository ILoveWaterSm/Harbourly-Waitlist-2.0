An accordion row between two 2px rules, with a circular plus that rotates to a cross when open.

Use `hb-faq` as the list wrapper (max 820px, centred) and one `hb-faqitem` per question; add `open` to expand. Questions are Sora 600; answers are `muted` body text. Consumers provide the toggle logic and should set `aria-expanded` on the button.
